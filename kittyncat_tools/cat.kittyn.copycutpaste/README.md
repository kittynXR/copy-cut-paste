# cátte — Copy Cut Paste

Adds 3 much needed buttons to Unity assets: Copy, Cut, and Paste.

## Features

- **Copy**: Copy selected assets for duplication
- **Cut**: Cut selected assets for moving
- **Paste**: Paste copied/cut assets to selected folder
- Preserves asset references and metadata
- Works with multiple selected assets

## Installation

Install via VRChat Creator Companion (VCC) or add to your Unity project's Packages folder.

## Usage

1. Select one or more assets in the Project window
2. Right-click and choose **Copy** or **Cut** from the context menu
3. Navigate to the destination folder
4. Right-click the folder and choose **Paste**

The tool will automatically generate unique names if assets with the same name already exist in the destination.

## Requirements

- Unity 2019.4 or later
